## 运行记录与边界

- `pnpm build`：TypeScript strict、Vite demo、esbuild 插件打包通过。
- `pnpm verify:plugin`：原有集成检查及新增预设、保存草稿、动态叙事、回放、隐私、会话隔离和历史上限检查通过；1500 调用及叙事的一次本机检查约 3 ms，不作为持续帧率基准。
- `git diff --check` 通过。
- 浏览器验证夹具与截图位于忽略提交的 `artifacts/world-check/`。插件夹具使用宿主颜色变量及可观察接口的模拟服务，未启动真实模型执行，也未在实际 Desktop profile 中升级或验证模型写文件全过程。
- 动态叙事使用事件模板持续生成；没有实现持续调用独立 AI 改写整个世界观。该范围符合用户的明确选项回复。
- 不自动保存动态篇章；它们由当前已加载事实重建。历史缺页仍以工作流提示为准。
